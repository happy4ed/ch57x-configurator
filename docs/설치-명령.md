# CH57x 설정기 — 설치 명령

윈도우 PowerShell 에 **아래 한 줄을 붙여 넣고 Enter** 만 누르면 설치가 끝난다.
시작 메뉴에서 `PowerShell` 을 검색해 **그냥 실행**한다. 「관리자 권한으로 실행」 은 필요 없다.

```powershell
[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $p="$env:TEMP\ch57x-install.ps1"; iwr -UseBasicParsing 'https://raw.githubusercontent.com/happy4ed/ch57x-configurator/master/install.ps1' -OutFile $p; Unblock-File $p; powershell -NoProfile -ExecutionPolicy Bypass -File $p
```

같은 줄을 다시 실행하면 **최신 버전으로 업데이트**된다. 따로 지우고 다시 깔 필요가 없다.

---

## 변형 — 필요할 때만

기본은 런타임을 포함한 포터블 판이라 어느 PC 에서나 그냥 돈다. 아래는 선택이다.

**.NET 8 데스크톱 런타임이 이미 있는 PC** — 약 0.3MB 짜리 작은 판을 받는다.

```powershell
[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $p="$env:TEMP\ch57x-install.ps1"; iwr -UseBasicParsing 'https://raw.githubusercontent.com/happy4ed/ch57x-configurator/master/install.ps1' -OutFile $p; Unblock-File $p; powershell -NoProfile -ExecutionPolicy Bypass -File $p -Slim
```

**특정 버전이 필요할 때** — 끝의 태그만 바꾼다.

```powershell
[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $p="$env:TEMP\ch57x-install.ps1"; iwr -UseBasicParsing 'https://raw.githubusercontent.com/happy4ed/ch57x-configurator/master/install.ps1' -OutFile $p; Unblock-File $p; powershell -NoProfile -ExecutionPolicy Bypass -File $p -Tag v0.2.0
```

---

## 이 한 줄이 대신 하는 일

| 단계 | 하는 일 | 왜 필요한가 |
|---|---|---|
| 1 | GitHub 최신 릴리스에서 zip 을 받는다 | 수동으로 릴리스 페이지를 찾아갈 일이 없다 |
| 2 | **출처 표식(Mark of the Web)을 지운다** | 이 표식 때문에 실행할 때마다 「Windows 의 PC 보호」 경고가 떴다 |
| 3 | 실행 중이면 먼저 끝낸다 | 트레이에 떠 있는 상태에서는 파일을 덮어쓸 수 없다 |
| 4 | `%LOCALAPPDATA%\Programs\Ch57x` 에 설치한다 | **재부팅에 사라지지 않는 자리** |
| 5 | 실행한다 | 트레이에 바로 올라온다 |

**설치 위치가 고정인 이유가 핵심이다.** 다운로드 폴더나 압축 파일 안에서 바로 실행하면, 윈도우가
그 자리를 지울 때 자동시작 등록이 **아무 사유도 남기지 않고** 통째로 사라진다. 2026-09-13 에 실제로
겪은 사고이며, 자동실행이 안 되던 진짜 원인이었다. 이 명령은 그 자리를 애초에 피한다.

---

## 건드리지 않는 것

- **프로필** — `%AppData%\Ch57x\Profiles`(설정은 `%AppData%\Ch57x`). 설치 폴더와 별개라 재설치·업데이트에 영향받지 않는다.
- **설치 폴더 전체** — 폴더를 지우지 않고 실행 파일만 덮어쓴다.
- **다른 프로그램의 자동실행** — `HKCU\...\Run` 의 `Ch57xConfigurator` 값 하나만 쓴다.

---

## 잘 안 될 때

**「스크립트를 실행할 수 없습니다」 류의 실행 정책 오류** — 한 줄 안에 `-ExecutionPolicy Bypass` 가
이미 들어 있어 이 오류는 나오지 않아야 한다. 그래도 나오면 한 줄을 **중간에서 잘라 붙였을 가능성**이
크다. 끝의 `-File $p` 까지 통째로 복사한다.

**「다운로드에 실패했습니다」** — 회사 네트워크가 GitHub 을 막고 있거나, `-Tag` 에 적은 버전이
없는 경우다. 태그를 뺀 기본 명령으로 다시 해 본다.

**「설치 폴더에 파일을 쓰지 못했습니다」** — 백신이 막고 있거나 프로그램이 아직 살아 있다.
트레이 아이콘에서 우클릭 → 종료 후 다시 실행한다.

**설치는 됐는데 자동실행이 안 붙는다** — 트레이 우클릭 →
`윈도우 시작 시 자동실행` 을 켠다. 메뉴에 빨간 경고 줄이 보이면 그 줄을 눌러 그 자리에서 고친다.

---

## 지우려면

1. 트레이 우클릭 → `윈도우 시작 시 자동실행` 을 꺼서 등록을 해제한다.
2. 트레이 우클릭 → `종료`.
3. `%LOCALAPPDATA%\Programs\Ch57x` 폴더를 지운다.
4. 프로필까지 지우려면 `%AppData%\Ch57x` 를 지운다 (프로필 파일은 그 아래 `Profiles`). 남겨 두면 다시 깔았을 때 그대로 쓴다.

---

## 근거

- 스크립트 진본 — 저장소 최상위 `install.ps1`
- 설치 경로 진본 — `windows/Ch57x.App/AutoStart.cs` 의 `StableFolder` · `StableExePath`
  (스크립트가 이 값과 글자 그대로 같아야 하며, 다르면 코드 쪽이 진본이다)
- 프로필 경로 진본 — `windows/Ch57x.App/ProfileManager.cs`
- 자동실행 레지스트리 — `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 의 `Ch57xConfigurator`
